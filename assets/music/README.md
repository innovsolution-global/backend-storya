# Musiques de fond

Déposez ici des pistes **libres de droit** (MP3) pour la musique des vidéos :

| Fichier       | Choix dans l'app |
| ------------- | ---------------- |
| `douce.mp3`   | Douce            |
| `epique.mp3`  | Épique           |
| `joyeuse.mp3` | Joyeuse          |

La piste est mise en boucle sur toute la vidéo et atténuée sous la voix off.

Sans fichier, Storya génère une nappe musicale simple avec ffmpeg, pour que la
vidéo ait toujours un fond sonore.

Sources possibles : [Pixabay Music](https://pixabay.com/music/),
[Free Music Archive](https://freemusicarchive.org/) (vérifiez la licence de
chaque piste, CC0 ou CC BY de préférence).
